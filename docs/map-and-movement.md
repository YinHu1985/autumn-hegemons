# 道路、地图模式与地点选择

更新：2026 年 11 月 15 日。外交已接入数值关系与使者任务，见 [外交设计](diplomacy-design.md)。

## 路网与进攻范围

春秋、战国两个剧本共用 96 城与 242 条双向道路。道路首先依据相邻辖区生成候选，再排除穿过湖海的直线；吴—延陵用绕行点避开太湖。这是游戏路网，不声称复原历史道路。

“相邻进攻”具体解释为**国家接壤**：目标城邑属于关系险恶（低于 −100）的国家，而且与本国当前拥有的至少一座城邑存在一条直接道路。沿用全国军团调度池，不要求参战军团先驻扎在该边城。夺城、失城立即改变后续可发起进攻的范围；已经建立的战役不因之后失去道路接壤或关系改善而自动取消。友方城镇之间的调动保持原有规则和行军时间。

玩家命令、旧调动入口转为攻击、AI 选择目标共同调用 `simulation/geography.ts` 的 `canAttackCity`。界面高亮只是展示结果，底层命令会再次校验，不能通过其他入口跳过限制。

道路属于剧本内容数据，与显示辖区的 SVG 几何分开：

```json
{
  "roads": [
    { "from": "linzi", "to": "qufu" },
    { "from": "wu", "to": "yanling", "via": [{ "x": 1273, "y": 640 }] }
  ]
}
```

`from`、`to` 引用城邑 ID，道路无方向。`via` 是可选底图绕行点，只决定画法，不增加中间可攻城邑。校验拒绝未知城邑、自连、重复道路与非法坐标。`scripts/suggest-roads.mjs` 向标准输出生成候选，不会在构建地图时覆盖手工调整的路网。

内容没有 `roads` 时，`definitions/roads.ts` 按坐标提供确定性的近邻连通图；计算不读取地图图像，也不保证自动避开水域。发布内容应显式编写道路。显式 `roads: []` 表示没有道路，不触发自动生成。

## 地图模式

右下角地图菜单和小地图仍为一体，不增加颜色图例。

| 模式 | 展示 |
| --- | --- |
| 列国 | 按城邑当前国家归属着色，显示国家疆界与国名 |
| 地形 | 按城邑定义的地形着色，城名标签附平原、丘陵等名称 |
| 道路 | 显示实际用于进攻邻接的路网；选中、悬停城邑突出相连道路 |
| 外交 | 相对玩家国家显示本国及险恶、不和、友好、亲密四档，国名旁附关系文字和数值 |

小地图同步当前模式；城邑提示同时显示归属、地形、关系与规模。外交显示读取运行状态而非剧本初始归属，因此占领与玩家国家变化能够正确反映。

运行状态的 `diplomacy.relations` 保存全部国家对，每条记录为 `{ nations: [国家ID, 国家ID], value: 20 }`，关系对称。新局全部为 +20 友好，只有险恶才提供出兵资格。外交任务按日改变关系，每年向 +20 回归 1 点。存档验证拒绝未知国家、缺失国家对、自身关系和重复记录；只接受当前版本格式。

## 通用地点点选

`game/map/useMapLocationSelection.ts` 保存界面临时请求：标题、说明、合法城邑 ID、非法地点提示，以及选择／取消回调。它不计算军令、不修改模拟世界，也不写入存档。以后建筑等地点操作可复用此接口并自行提供候选和后续确认流程。

当前出征流程：

1. 在军府点击“到大地图选择目标”。
2. 暂停世界时间，隐藏原操作窗口但保持其组件和编组草稿；地图突出合法城邑并显示道路。
3. 点击己方其他城邑作为调动目标，或点击直接接壤且关系险恶的城邑作为进攻目标。非法点击提示具体原因。
4. 选定后回到原军团详情，显示目标和军团选择，玩家再确认军令。点选本身不发起战役。

Esc 或取消恢复原窗口；点选期间点击当前军府入口也回到草稿。切换其他政令或打开系统菜单会清理点选请求。完成或取消后保持暂停，由玩家继续时间。

## 验证

自动测试覆盖路网连通与水域避让、道路内容校验、夺失城后的邻接、非法军令不修改世界、AI 使用相同规则、外交任务存读与地图显示。浏览器检查以 1920×1080 为主，另检查 1280×720 的菜单和点选提示边界。
