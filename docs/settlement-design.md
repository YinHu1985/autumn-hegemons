# 城镇、治理与粮食财政

记录日期：2026 年 11 月 10 日。

本文件记录本轮确认的简化城镇方案：地形、可扩建规模、治理效率和专门建筑共同决定地区发展，暂不模拟实际人口、城乡人口或国人／野人阶层。采用方案 A：规模本身提供基础财政、人力和建筑容量，建筑负责专业分工及额外收益。总体记录见 [设计讨论](design-discussion.md)，产业见 [特产与生产](production-design.md)。

## 已确认的分工

| 要素 | 当前规则 |
| --- | --- |
| 地形 | 每个城镇具有地形，影响作战与战场生成，也影响建设成本和速度 |
| 规模 | 花费主货币和时间扩建，提供基础收入、人力上限、人力增长及建筑容量 |
| 治理效率 | 体现行政执行力，影响实际收入、人力上限及人力增长；上限受国家政策、科技等影响 |
| 专门建筑 | 提供特产、加工、军备或其他能力；部分建筑额外提供财政收入 |
| 人口 | 当前抽象进规模与人力，不建立人口增长、社会阶层和劳动力分配系统 |
| 地区发展 | 扩大规模、建设专门建筑、提高治理效率 |

规模只给容量、全部收入和人力都靠建筑的方案 B 当前不采用。“少数建筑增加收入”指建筑种类可以较少，不要求这些建筑的收入贡献很小。

## 地形

当前保留平原、森林（forest）、丛林／雨林（jungle）、丘陵（hill）、高山（mountain）、沼泽、沙漠、冻土八类；部分地形在中原地图中可能不用，仍可保留定义。

地形参与建设成本与速度修正，并为战斗加成和战场生成保留接口。具体系数、战斗影响和生成规则以后确定。建议用城镇主地形影响战场各类地形的分布，不要求整张战术地图都是同一种地形；此生成方式仍是实现建议。

## 扩建与建筑容量

扩建需要花费粮食财政与时间。最终成本和工期可以受地形、国家能力及其他修正影响，原型先使用固定基础成本和工期。每城同时只能施工一项建筑，不同城镇可以并行；扩城是否占同一队列、取消退款及易手后的施工处理仍待定。

规模提供个位数数量级的建筑容量，小城可以仅有一个建筑位，升级不增加占用，不再要求真实人口数量。通用建筑与产地建筑是否占位、同类作坊如何管理、建筑容量是否适用能力软限制仍需明确。

建议现成作坊的产出主要由自身等级／规模及相关修正决定，不再自动乘一次城镇规模。规模与建筑容量的具体公式后定。

## 治理效率

城镇记录当前治理效率，上限由国家政策、科技等能力决定。新占领地区需要恢复治理；叛乱等情况会降低效率，之后重新恢复。当前用这一个值处理行政发挥程度，暂不另设稳定度。

实际收入、人力上限和人力增长，以城镇规模与治理效率为基础计算，建筑和其他 modifier 可进一步影响，具体公式未定。当前值、上限与恢复速度需要区分；恢复周期、是否需要额外投入、上限变化的处理，以及“国家政策”具体来自理念、政体还是独立政策系统，仍待讨论。

治理是否同时降低所有作坊的商品额度尚未确认。此前助手倾向让治理影响有效生产能力，这是建议，不能仅凭“治理影响收入”就自动扩展到全部商品。

## 粮食作为主财政

粮食取代此前统称的金钱，成为可以积累、支付开销的主财政资源。城镇基础收入可理解为辖区基础赋入；扩建、建设、研究、征召、军费等原本的金钱支出改用粮食财政。

这是以粮食统一计量国家可支配财力的游戏抽象，不主张春秋战国各国历史上统一采用粮食本位货币。

| 资源角色 | 当前处理 |
| --- | --- |
| 粮食财政 | 有国库余额、收入与支出，可以结余 |
| 铜、铁、木材、黄金等商品 | 采用持续产出与占用额度，当前不积存商品库存 |
| 人力 | 有实际可用人数、征发与伤亡，不能与财政余额或商品额度混用 |

财政粮食结余不意味着启用完整商品仓储，也不自动加入居民口粮、粮食腐败、粮运网络或随军口粮系统。征召仍只支付主财政并占用人力，不另查铜铁、布匹或专业军备额度。

月底维护采用各大类独立的足额支付比例滑条。余额加收入不足时，各类计划支付统一同比缩减；本月收入按已有运行状态结算，月底实付决定下月运行状态。详细公式见 [首版结算规则](core-rules.md)。

丝绸、盐、制衣等经济收益可以折算为粮食财政收入，不要求它们物理生产粮食，也不因此预设国家贸易系统或所有商品自动兑换粮食。

## 粮食特产与统一仓库

粮食、鱼及可选的稻、粟等地域变体，提供同一种主财政粮食；可以有不同特产名称和美术，但无需分成不能互用的财政资源。

粮食类产地建筑统一为“仓库”，对应暂名为仓库、改良仓库、先进仓库。升级后的额外财政收益可解释为更好的收集、保管和减少浪费。这个收入是规模基础赋入之外的特产收益，具体采用加值还是其他方式以后确定。

原先农业的农庄、渔业的渔场不再作为独立建筑类型；原非军工二级仓库并入本定位，不再另占一个加工设施类别。这里的仓库首先是粮食类特产对应的产地建筑，未额外确定所有非粮食地区也可建设同样的收入建筑。

农业、渔业、仓储三条科技合并为一条三级农业路线，暂沿用“畎亩耕作 → 沟洫灌田 → 精耕细作”。原渔业与仓储六项科技退出当前清单；生产科技从 75 项减为 69 项，另有 18 项军事科技，共 87 项。详细清单见 [暂定科技设计](technology-design.md)。

原先“仓库消耗陶器获得特殊加成”只是旧候选，不自动成为新仓库的条件。是否使用陶器、如何使用以后再议；改善仓库不自动意味着新增一条需逐月计算的腐败率或仓容量。

黄金保留为常规商品资源，用途尚未确定；与玉一起参与高端理念或科研组织能力只是候选，不预设兑换财政、库存或必须拥有金矿的研究条件。

## 全国人力与剩余边界

人力采用唯一的全国池，军团征募、补员与地方守备共用，不另设防御专用储备。在役不占池子上限，征发从池子进入部队，复员返还实际人员，超出池子上限的部分抹除。失城扣除相应上限，并按上限缩减比例扣除池内存量，例如上限 100 变 90、存量 50 变 45；同次失城只缩减一次。每月按全国上限的 1.5% 恢复空缺。

此规则替代按省保存与在役占容量的候选，不引入实际人口模型。得城、扩城或治理恢复只增加容量、靠恢复补充存量。地方守备决战就绪时从该池动员，战后幸存者回到同池并裁切超额；其他原因上限下降的细则以后调整。具体记账见 [首版结算规则](core-rules.md#全国人力池)。

政策与叛乱留待以后；外交采用关系数值与使者任务，仅险恶关系允许进攻相邻城邑。占领即割地、全部城镇丢失即灭国。首都仅是标记，不提供特殊能力。
