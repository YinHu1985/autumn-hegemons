记录始于 2026 年 11 月 8 日，最近更新于 11 月 15 日。`web/` 已开始实现最小经营原型；完整游戏设计仍在本目录逐步细化。

战争采用按防守国家排队的准备期与完整野战，具体规则以 [战斗与动员设计](battle-design.md) 为准。可同时发动多场进攻；防守队首正常推进，后续最多完成一半准备。满进度暂停等待玩家选择手动或托管，不另给三十日窗口、不提供预约功能。旧方案保存在 [历史记录](battle-design-history.md)，不再作为当前要求。

独立围城与援军已取消。进攻额外维护、结束后延迟回池；防守立即回池但保留损失。近期参战后再主动进攻增加疲劳，防守不新增；已有疲劳攻守均生效，池中休整清除。常备决定专业兵种与主要输出，征召承担主要损耗。全国只保留一份人力池，军团征募、补员与地方守备共用；地方守备决战就绪时动员一次，幸存者战后返还同池。

城镇采用规模提供基础财政、人力和建筑容量的方案 A，人口暂时抽象；地形影响建设与战斗，治理效率影响收入和人力并在占领、叛乱后恢复。粮食是可积累主财政，铜铁黄金等商品继续使用额度；详细共识见 [城镇设计](settlement-design.md)。

生产按特产产地与城市加工两层组织。粮食、鱼及作物变体统一使用仓库增加粮食收入；军工已选二级军备额度，由兵种模板占用。国家本身还可独立提供任意配置资源，用于开局启动和平衡；原少量常备保障归入该来源，首都只作标记。一地国不要求完整产业链，贸易作坊仍只是候选，见 [特产与生产设计](production-design.md)。

各大类独立设置足额维护比例，财政不足时按同比例缩减计划支付。本月收入按既有运行状态结算，月底实付决定下月状态；军队、建筑和科研都需定义低维护效果。每城同时只能施工一项建筑，城间并行，升级不额外占建筑容量。

国家开局关系 +20，关系险恶才可出兵；占领即领土转移，失去全部城镇即灭国，玩家代表国家。人才招募满 20 年后每月随机退场，事件超时默认第一项。组织能力采用有明显惩罚的软上限；政策与叛乱留后，外交关系与使者任务见 [外交设计](diplomacy-design.md)，完整规则见 [首版结算与运行规则](core-rules.md)。

农业、渔业、仓储合并后，科技暂列 69 项生产科技，再加 18 项军事占位，共 87 项。科研采用高阶名义工作量递增、同类低阶成果提供大量进度启发的暂定机制；具体成本、启发比例、加成与解锁功能待定。暂不以年代或理念层次作为通用门槛，详见 [暂定科技设计](technology-design.md)。

科技组另设可成长的单组规模，玩家可调整每月基础投入，人才与特长影响效率。扩大单组规模与增加并行科研席位分开，超限适用范围、进度和费用公式仍待细化。

理念共用科研系统，作为独立项目分布在三个成本档位，不设研究前置，可以直接研究高成本理念。同方向启发只降低工作量；研究解锁后按槽位实行，槽位解锁另议。理念清单不计入上述 87 项生产与军事科技。

游戏内容、数值和关系从第一天起采用 JSON 等文本定义，代码实现通用效果与规则；新增普通货物或建筑应贯通模拟、界面和 AI，无需逐项改代码。已决定继续采用 Web，具体边界见 [架构与数据驱动设计](architecture-design.md)，TypeScript、Worker 与具体库属于实施规划。

网页提供各类内容定义的编辑界面，与直接编辑 JSON 共用格式和校验。具体兵种模板由数据定义，程序实现基础大类语义与计算词条。模块与目录方案见 [网页架构规划](architecture-plan.md)，尚未实现。本轮回答足够支撑首版详细设计，剩余为商品分配、月内新增状态等操作边界及数值，见 [完整计划审查](design-gap-review.md)。

## 阅读约定

- **已确认方向**：用户明确提出的边界，或在讨论中明确选择的方案。
- **用户设想**：用户希望保留、探索或调整的玩法方向；标为探索的部分仍需细化。
- **讨论建议**：助手提出的整合方案，尚未自动成为最终规则。
- **参考实现事实**：参考项目当前代码的行为，不代表新项目必须采用。

示例预算、产量、科技数量和原型规模都不是已经确定的平衡参数。后续修改应同步更新对应规则的状态，避免把讨论建议误当作已确认决策。
