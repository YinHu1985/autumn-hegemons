# 春秋风云 · 地图与剧本

本轮把原 23 城原型扩为 **96 城**，两个开局使用相同的城镇 ID 和坐标。地图涵盖关中陇右、河汾太行、燕赵、齐鲁、中原、江汉、吴越和巴蜀；河西、岭南和朝鲜半岛暂不铺设可占领城邑。

## 两个开局

| 剧本 | 开始时间 | 国家数 | 城镇数 | 推荐国家 |
| --- | --- | ---: | ---: | --- |
| 春秋初期 · 平王东迁 | 前 770 年 | 28 | 96 | 齐、晋、楚、秦、郑、吴 |
| 战国初期 · 三晋列侯 | 前 403 年 | 17 | 96 | 齐、秦、楚、魏、赵、韩、燕 |

推荐国家只是开局快捷入口。每个剧本内所有国家均可选择，小国不被隐藏或锁定。魏使用 ID `wei_state`，卫使用 ID `wei`，以免同音混淆。

春秋剧本包括齐、鲁、楚、秦、晋、燕、周、郑、宋、卫、陈、蔡、曹、莒、徐、滕、吴、越、巴、蜀、申、随、邓、曾、义渠、代、鲜虞、邢。它以列国并存为主，安排多个一城小国；齐晋秦楚、燕和南方势力已经有可经营的区域。

战国剧本以七雄为主，同时保留鲁、周、郑、宋、卫、越、巴、蜀、中山、义渠。晋地分给韩赵魏；陈蔡申邓随曾等区域并入楚，曹地并入宋，莒地并入齐，吴地由楚越分占。没有另设晋公残余领地，也没有把北部所有族群拆成独立国家。

## 地名和疆域的取舍

这是以游戏性为先的近似剧本，不是前 770 年或前 403 年的精确疆域复原。早期秦、晋、楚、燕的可控区域有所放大，吴越巴蜀等统一作为可选国家；前 403 年开局采用便于理解的七雄与周边小国形势。边疆城邑可代表周边聚落与资源区，不表示当年已经存在同等规模的城墙城市。

优先保留熟悉的先秦地名；难以确定或过于生僻时，采用秦汉县郡名。天水、北地、陇西、东莱、辽西、辽东、武陵、罗县、涪县、汉昌、朱提等都属于便于识别的区域标签，不应根据显示名推断建城年代。临淄与旧营丘不再同时代表齐都，旧 `yingqiu` 条目保留 ID 而改名广饶。

坐标沿用参考项目 C 的 1800×1500 地图投影（东经 93–132 度、北纬 43–17 度），新城按近似地理位置落点。多数旧城坐标保留，雍与陈仓原先过近，调整为 `(655,475)` 与 `(650,510)`；琅琊与湘北罗县的点位向岸内略移，以免落在海岸或洞庭湖遮罩里。旧 23 城存档使用独立兼容地图，当前两个剧本共享扩展后的地图。

城镇以现有地形、特产、规模、治理和建筑定义配置。13 类基础特产全部保留：粮食 30 城、木材 11 城、铜 8 城、牛 7 城、麻／丝绸／鱼／马各 6 城、盐／铁各 4 城、黄金／陶器各 3 城、玉 2 城。此分布用于资源经营与扩张选择，不表示准确的古代矿产产量调查。

首都标记尚未接入专门国家能力；重要中心的较高规模只是初始城镇数据。春秋大国中心一般规模 3，战国一般规模 4，小国中心规模 2；各地初始仅一座对应特产作坊，中心另有市场和城墙。国家基础资源沿用原型保障，提供粮食及少量基础军备；一城小国仍可凭国家配额和征召起步。初始人力按本国容量约束到合理范围，大国不会仅因新增城市就立即拥有数倍常备军。

## 文件与维护

- `web/public/content/base/scenarios.json`：剧本目录、默认剧本和文件引用。
- `web/public/content/base/scenario.json`：春秋剧本完整数据，作为默认开局。
- `web/public/content/base/warring-states.json`：战国剧本完整数据。
- 剧本内 `id`、`name`、`description`、`recommendedNations` 为开局展示信息；国家 `description` 说明位置与玩法倾向。
- 两剧本城镇的 ID 和坐标保持一致；修改城名、初始归属或发展程度不需重绘疆界。修改坐标或增删城市后需要重新运行地图预处理。
- 辖区是按城镇位置生成的游戏化邻近区域，运行时按国家归属着色；疆界不直接写死在图片或国家数据中。

## 史实参考与边界

平王东迁作为前 770 年开局锚点，参照复旦大学出土文献与古文字研究中心关于春秋分期的资料；各家分期并不完全一致，本项目只使用这一常见开局节点。[春秋史分期和断代研究](https://www.fdgwz.org.cn/Web/Show/3157)

前 403 年韩赵魏列为诸侯，适合作为三晋已经独立的游戏开局；它不是对战国唯一起始年代的裁定。[上海社会科学院《列国争雄》介绍](https://www.sass.org.cn/_t31/2006/0314/c1204a38934/page.htm)

齐的都城沿革与临淄位置参考北京大学考古文博学院讲座纪要。古蜀材料体现都城与年代存在不同记载，因此本项目用成都及附近秦汉易识地名表达整个区域，没有强行复原每一代王都。[秦汉地方城邑](https://archaeology.pku.edu.cn/info/1031/4579.htm)、[先秦蜀国的都城和疆域](https://www.nopss.gov.cn/n/2013/0419/c362367-21203630.html)

罗县采用秦汉县名表达湘北区域；其古城与县境演变参照汨罗地方沿革。汉昌作为巴中区域标签，参照地方政务史料所列东汉县名。[汨罗历史沿革](https://www.miluo.gov.cn/25214/25216/content_1309312.html)、[巴中历代州郡县置废简述](https://www.scpczx.gov.cn/show.asp?id=50)

国家数量、城市数量、归属、资源与起始规模是本轮暂定游戏设计，不由以上历史资料直接推导；后续可以在同一文本结构中调整。
